# Intuitive Loop Resolution

This release resolves the current high-impact loop findings by consolidating existing systems. It does not add a disposable currency, a parallel minigame, or another permanent dashboard.

| Finding | Shipped resolution | Acceptance signal |
| --- | --- | --- |
| One dynamic primary action | The contextual guidance button now owns plan selection and the active plan control appears only after a plan is filed. | A new shift presents one highlighted `FAST / SAFE / FLOCK` decision. |
| Contextual HUD modes | Clean-clutch and reward tracks remain hidden until they have state worth reading; rival pressure still waits for the first delivery. | Zero-value reward furniture no longer competes with the current action. |
| Physical routing | Intake trays support click-to-arm and drag-to-hen. A miss safely returns the tray. | Drop raycasts only against marked hen pick areas and commits through simulation authority. |
| Office teaches the loop | The persistent four-step icon rail and physical folder/egg/farmer journey communicate plan, work, response, and reward. | The same causal journey remains visible without opening Flockwatch. |
| Fast first payoff | The first career file receives a temporary 35% production boost and cannot crack. | Automated simulation reaches a clean first egg within the bounded opening fixture. |
| Concise receipts | Decision feedback displays at most three consequence chips while accessibility metadata retains the full breakdown. | Visible count is capped at three; exact detail remains inspectable. |
| Tangible rewards | A physical three-egg shelf lights for plan filed, contract complete, and reward claimed. | Atmosphere diagnostics expose `visible_reward_eggs` from 0 through 3. |
| Distinct strategies | Fast, Safe, and Flock keep their authoritative modifiers and now tint the office's ambient identity. | Strategy ID and color survive snapshot refreshes without changing furniture layout. |
| Deliberate tension curve | Atmosphere derives plan, build, pressure, recovery, and finale beats from time and quota state. | The pacing stage is deterministic and inspectable. |
| Push your luck | Reaching quota opens a once-per-shift choice: bank the clutch or chase premium value with explicit pace and shell-risk tradeoffs. | The choice is unavailable before quota and cannot be filed twice. |

| Short character communication | Hens bark fragments such as `PERFECT FIT`, `RISKY ROUTE`, `CLEAN SHELL`, and `TOGETHER` at the relevant world position. | Copy is capped at 22 characters and does not open a modal. |
| Relationships signal gameplay | Team Lift makes both bonded hens answer together and retains its existing paired marker and authoritative morale/attention effect. | Both world views share one receipt authority key and spatial bark. |
| One shift spectacle | Claiming a contract reward fires the physical shelf celebration and strategy-colored office burst. | The reward remains exact-once because the contract reward is exact-once. |
| Human comprehension gate | The protocol below defines an unaided first-session check. Automated checks validate instrumentation, never invent participant results. | A release can report human comprehension only after signed session evidence exists. |

## Unaided comprehension protocol

Use five participants who have not seen the project. Give only: “Run the office for one shift.” Do not explain controls or terminology.

Record whether each participant can, without coaching:

1. identify the highlighted next action within 15 seconds;
2. explain `file → hen → egg → fund` after the first delivery;
3. route one file by click or drag within 60 seconds;
4. describe the chosen plan's gain and risk;
5. recognize why the physical reward shelf changed;
6. recover from one missed drop without restarting.

Release target: at least four of five participants complete items 1–3, and at least three of five correctly explain items 4–6. Store observations through the existing usability session/evidence tools under `tools/`; do not mark this gate passed from developer familiarity or automated screenshots.
