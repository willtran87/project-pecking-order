# Guided Strategy and Payoff Resolution

This pass resolves the 24-item intuitiveness, fun, reward, and replay list by
consolidating the existing game rather than adding another economy or default
panel. The authoritative Active Playbook now begins with three one-click plans;
the existing office, hens, production chain, campaign, and rewards supply the
depth behind those choices.

Automated evidence proves behavior, persistence, accessibility semantics,
layout, and release parity. It does not claim that unobserved people found the
game fun or habit-forming; the repository's moderated playtest protocol remains
the acceptance boundary for subjective comprehension and enjoyment.

## Clarity and first decisions

| # | Requested improvement | Resolution |
|---:|---|---|
| 1 | Three strategy presets | **Fast**, **Safe**, and **Flock** atomically file a contract, floor focus, preparation, and personal goal. The active policy recommends one without filing it automatically. |
| 2 | One action, one world target | The current action publishes one semantic target contract; the existing camera, hen selection halo, tray focus, and control pulse carry the player to it. |
| 3 | Animated consequence previews | Every plan exposes exact gain, cost, and risk plus its physical target before authority changes. Filed choices retain the existing three-delta receipt. |
| 4 | Reduce vocabulary burden | The guided layer groups play under **Inspect → Route → Help → Peck → Invest**. Complete system names remain secondary tooltip and accessibility detail. |
| 5 | Smart defaults | The policy-fit plan is marked with a star and can be accepted in one action. Custom planning unlocks after Shift 1 and remains opt-in. |
| 6 | Visible shift journey | The permanent four-icon rail now communicates **Plan → Work → Respond → Reward**, while the file → hen → egg → credit chain remains available as the production diagnostic. |
