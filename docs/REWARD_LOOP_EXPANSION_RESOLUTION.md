# Reward Loop Expansion Resolution

This pass turns the latest fifteen engagement ideas into one compact,
presentation-only layer over the existing simulation. It does not add a second
economy, hidden difficulty scaling, a new save authority, or another default
panel. Exact terms remain available through hover, keyboard focus, dossiers,
and the filed review.

## Player-facing hierarchy

The permanent rail uses only four additional 16-pixel shapes: hen for signature,
target for optional contract, linked marks for combo, and egg for the next
reward. The three clean-clutch eggs sit beside the compact `×N` count. This keeps
the default office readable while the complete fifteen-item projection remains
available to accessibility and browser diagnostics.

## Verification boundary

`tests/gameplay_pulse_director_test.gd` proves all fifteen keys are present,
presentation-only, and linked to representative authoritative state.
`tests/management_loop_ui_test.gd` proves the four-icon pulse, three-egg track,
filed strategy identity, and rival rule reach the live office. The production
browser audit validates the same contract after entering a real shift. Whether
the result is subjectively more fun or addictive still requires human play and
is not claimed by automation.
