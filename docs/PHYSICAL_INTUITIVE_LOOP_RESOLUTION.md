## Safety and proof boundaries

- `ChickenView.management_selection_requested` carries only a stable worker ID. Office remains the sole owner of camera focus and dispatch commit, so the world target cannot duplicate routing or workers.
- World previews and the physical-loop read model are explicitly non-authoritative and never award, spend, save, or file a choice.
- Quick Start resets to Standard / Open Nest / Baseline before emitting the existing zero-argument new-campaign intent. Customize uses the unchanged selectors and replacement safety flow.
- Automated coverage proves state contracts, input routing, stable IDs, reversible previews, responsive layout, persistence, production export, and browser errors. Whether the result is subjectively fun still requires human playtesting; no automated run is represented as that evidence.
