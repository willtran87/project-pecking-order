# Intuitive Reward Loop Resolution

This pass resolves the twenty approved improvements as one professional, icon-first management loop. It adds no parallel economy, save authority, difficulty mutation, mandatory dashboard, or fabricated participant evidence.

## Player-facing outcome

The office now communicates the loop physically: choose a morning plan, route the shift's hero file, make one manager call, watch the flock respond, and see the result land in a visible reward destination. Details remain available on hover, focus, `MORE`, and hold-`H`; the default view stays concise.

## Technical boundaries

- `GameplayPulseDirector` version 12 exposes an exact twenty-item `intuitive_reward_loop` read model.
- `ManagementPresence` owns only the physical station and its interrupt-safe visual sequence.
- `DepartmentSimulation` remains the sole authority for plans, interventions, resources, workers, and outcomes.
- Case-folder markers and station props have no collision, so chicken navigation is unchanged.
- Intervention sounds reuse the fixed eight-voice pool and existing semantic buses.
- Older save compatibility is unchanged because this pass adds no persisted state.
