# Core Loop Mastery Completion

This pass resolves the latest twenty-item gameplay brief at the point of play. It adds no parallel economy, save state, roster, or blocking panel. `DepartmentSimulation` remains authoritative; the nested `core_loop_mastery_polish` contract is read-only presentation and audit metadata.

## Routing clarity and file identity

1. **Target-hover forecasts** — Hovering a marked hen reveals only `PACE · SHELL RISK · FLOW`; focus and assistive copy expose the same facts without requiring hover.
2. **Distinct file personalities** — The next real queued file becomes `RUSH`, `RETURNED`, `PRIZE`, `FRAGILE`, `SENSITIVE`, `REPAIR`, or `STEADY` from deadline, rework, contract/value, and lane facts. There are no hidden personality rolls.
3. **One obvious opening move** — One armed file, one star-marked best hen, no required shortcut.
4. **Stronger action-to-result trails** — The existing physical sequence remains `FILE → HEN → EGG → SORTER → CREDIT`, with the affected hen and office reacting first.
5. **Visible consequence previews** — Star, check, and triangle previews disclose pace, shell risk, and flow before commitment.
6. **Consequential routing combinations** — Star builds flow by one, check preserves the current flow, and triangle resets it. These are authoritative outcomes, not decorative labels.

## Character, rivalry, and decisions

7. **Hen signature moments** — Existing signature Playbook actions use anticipation, action, hen reaction, and landed-result beats.
8. **Personal hen ambitions** — Each employed hen exposes one optional, state-derived ambition tied to career story with no miss penalty.
9. **Relationship-driven teamwork** — Existing pair abilities retain distinct outcomes, shared reactions, and persistent callbacks.
10. **Readable rival counterplay** — Rival intent, personality, response choices, and remembered history remain visible; there is no hidden counter.
11. **Mid-shift decision spikes** — Hero files provide at most three disclosed, valid answers during the shift.
12. **Better push-your-luck decisions** — Stakes appear before commitment, declining is valid, and banked rewards remain safe.

## Progression, recovery, and replay

13. **Transformative upgrades** — Rewards change available verbs and physical office state, not only percentages.
14. **Physical progression** — Reward sockets, office furnishings, and collection evidence show accumulated progress in the world.
15. **Recovery bargains** — Rescue and intervention choices disclose gain, cost, and risk while preserving earned rewards.
16. **Short counterfactual recaps** — Review stays near ten seconds: what worked, close call, one other path, next shift.
17. **Instant experimental rematches** — One-click same-seed rematches change one rule and never erase banked campaign progress.
18. **Strategy-shaped celebrations** — Celebration content reads the player's build and choice; intensity follows reward importance with reduced-motion parity.
19. **Adaptive guidance** — Guidance changes information density, never difficulty, offers `SHOW ME`, and retires after demonstrated mastery.
20. **Real first-shift observation** — Instrumentation records eye target, cursor path, first hesitation, and recovery path. The five-person study remains `AWAITING REAL PARTICIPANTS`; automated checks never impersonate human findings.

## Verification contract

- Native completion tests require the exact twenty unique item IDs.
- Routing tests require deterministic file personalities and truthful `FLOW +1 / FLOW HOLDS / FLOW RESETS` behavior.
- Office tests require hover forecast appearance and cleanup, file-personality diagnostics, shape parity, and assistive equivalents.
- The production browser audit requires version 20 of the gameplay pulse and the complete nested mastery contract.
