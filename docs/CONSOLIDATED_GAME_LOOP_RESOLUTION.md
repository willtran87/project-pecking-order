# Consolidated Game Loop Resolution

This pass makes the existing management game read as one loop: **NOW → WHY → REWARD**. It consolidates proven simulation, Active Playbook, chicken, rivalry, environment, progression, and story authorities instead of adding another economy, dashboard, or save format.

## Player-facing outcome

The player can enter a prepared First Clutch, choose a plan, route the hero file, watch the flock respond, and see the reward land. The visible guidance presents one primary action; the existing four-icon journey and physical command station carry the broader arc without increasing default text density.

## Authority and performance boundaries

- `DepartmentSimulation` remains the sole writer for money, hens, cases, plans, rewards, rival responses, bonds, mastery, and outcomes.
- `ConsolidatedGameLoop` is a pure `RefCounted` projection; earlier gameplay-pulse layers are compatibility inputs rather than new presentation destinations.
- Physical trails are interrupt-safe, node-bound tweens and add no collision or navigation changes.
- The save schema is unchanged.
- Existing fixed audio pools, responsive containers, and semantic icon grammar are reused.

The production browser audit verifies the same projection in the exported game and confirms the physical station consumes the canonical loop.
